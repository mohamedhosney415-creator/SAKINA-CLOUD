طريقة الحصول على ملف APK (بدون تثبيت أي شيء على الكمبيوتر)
==========================================================
مهم جدًا: لا تبنِ المشروع بأي أداة أخرى (Android Studio أو تطبيقات بناء) إلا عبر
setup_local.bat / setup_local.sh. السبب: مجلد android غير موجود داخل المشروع عمدًا،
ويُنشأ ثم يُجهَّز تلقائيًا (أذونات، خدمة الصوت، الويدجت، صوت الأذان). لو بنيته بدون
هذا التجهيز فسيُغلق التطبيق أو لن يعمل الأذان والتلاوة.

1) أنشئ حسابًا مجانيًا على github.com ثم مستودعًا جديدًا (New repository).
2) ارفع كل محتويات مجلد Sakina (وليس المجلد نفسه) إلى المستودع:
   Add file ← Upload files ← اسحب كل الملفات والمجلدات.
   تأكد أن مجلد  .github  ظهر في القائمة (أحيانًا لا يُرفع لأنه مخفي).
   لو لم يظهر: Add file ← Create new file ← اكتب الاسم:  .github/workflows/android-apk.yml
   والصق فيه محتوى الملف من الـ zip.
3) تبويب Actions ← Build SAKINA APK ← Run workflow.
   أول خطوة تفحص الملفات: لو فيه ملف ناقص ستكتب لك اسمه بالضبط.
4) انتظر حتى تظهر علامة صح خضراء (١٠–٢٠ دقيقة).
5) افتح التشغيلة ← Artifacts ← SAKINA-apk ← حمّل وفك الضغط ← ثبّت app-release.apk.

لو التطبيق يفتح ثم يغلق:
 أ) افتح نفس التشغيلة في Actions ← خطوة smoke-test ← Artifacts ← smoke-test-output
    (فيه screen.png لقطة شاشة، و logcat_full.txt). وافتح خطوة "Crash summary" وانسخ ناتجها.
 ب) أرسل لي: الجزء المنسوخ + لقطة الشاشة.
 ج) لو التطبيق يفتح ويظهر شريط برتقالي "حدثت أخطاء": اضغط عليه ← "نسخ التقرير كاملًا" وأرسله.

لو ظهرت علامة X حمراء في البناء: افتح الخطوة الفاشلة وانسخ آخر ٣٠ سطرًا من الخطأ.

للأذان: ضع ملفي afasy.mp3 و afasy_fajr.mp3 داخل assets/adhan قبل الرفع.
بعد التثبيت: اسمح بالإشعارات، وفعّل المنبهات الدقيقة، واستثنِ التطبيق من توفير البطارية
(الإعدادات ← إعدادات الأذان).
