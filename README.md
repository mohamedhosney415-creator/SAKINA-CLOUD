# سكينة — SAKINA 4.1.0

تطبيق إسلامي (Flutter / Android) بواجهة عربية RTL: مواقيت، أذان، قرآن، أذكار، ختمة، تقويم، رمضان، ويدجت.

> **حالة المشروع:** النسخة السابقة جُرّبت على هاتف المطور. تعديلات 4.1.0 في المشغل والواجهة لم تُبنَ أو تُختبر على جهاز بعد؛ شغّل GitHub Actions ثم اختبر APK الناتج قبل النشر.
> راجع `STATUS.md` لمعرفة ما يحتاج تأكيدًا، و`TESTING_CHECKLIST.md` للاختبارات الإلزامية.

## البناء (APK) من GitHub
1. ارفع محتوى هذا المجلد كما هو إلى مستودع GitHub.
2. تبويب **Actions** ← **Build SAKINA APK** ← **Run workflow** (أو يعمل تلقائيًا مع كل push).
3. حمّل الملف من **Artifacts** ← `SAKINA-apk`.
4. إن فشل البناء: افتح سجل الخطوة الفاشلة وأرسل الخطأ كما هو لتصحيحه.

الـ workflow ينفّذ: `flutter create` ← `tool/patch_android.py` (الأذونات، الخدمات، الويدجت، صوت الأذان، Gradle) ← `flutter build apk --release`.

## ملفات الأذان
ضع تسجيلاتك في `assets/adhan/` (راجع `assets/adhan/README.txt`):
`afasy.mp3` و`afasy_fajr.mp3`. بدونها يعمل التنبيه بصوت الإشعار الافتراضي.

## الخطوط
تُحمَّل أول مرة من الإنترنت. لتضمينها: `assets/google_fonts/README.txt`.

## الهيكل
```
lib/
  core/       التخزين، الإعدادات، الثيم، التنسيق، عناصر مشتركة
  data/       المدن، السور، الأذكار، الأحاديث، الحكم، المناسبات، أدعية رمضان
  services/   المواقيت، الإشعارات والأذان، القرآن والصوت، الختمة، سجل الصلاة، النسخ الاحتياطي، الويدجت
  features/   صفحات التطبيق
android_native/  ويدجت Kotlin + الموارد + الأيقونات (تُنسخ تلقائيًا للمشروع)
tool/patch_android.py
```

## ملاحظات تقنية
- المواقيت تُحسب محليًا بمكتبة `adhan` (الهيئة المصرية: الفجر 19.5° والعشاء 17.5°، مذهب شافعي للعصر) فتعمل بلا إنترنت وبتوقيت القاهرة مع التوقيت الصيفي.
- الأذان: إشعارات مجدولة (alarm exact) لـ14 يومًا وتُجدَّد كلما فُتح التطبيق، وتُعاد بعد إعادة تشغيل الهاتف عبر مستقبل الإقلاع.
- صوت الأذان يعمل بمستوى «المنبّه» في النظام.
- نص القرآن يُحمَّل من api.alquran.cloud ويُحفظ محليًا، والتلاوات من cdn.islamic.network (للتحميل أو البث).
- لا يطلب التطبيق GPS؛ اختيار المدينة يدوي. الحساب والمزامنة السحابية اختياريان. لا إعلانات أو أدوات تتبّع.

تطوير حُسْنِي

## إضافات SAKINA 4.0
- مساعد سكينة اليومي مع سجل نشاط محلي وسلسلة أيام.
- رحلتي مع القرآن: أيام القراءة، السور المقروءة، وآخر موضع.
- تحديات اختيارية للقرآن والأذكار والتسبيح.
- بحث في نصوص القرآن المحفوظة محليًا (حمّل النص كاملًا من صفحة التنزيلات لتفعيل البحث Offline الشامل).
- توسيع قائمة القرّاء مع الاحتفاظ بمشغل `just_audio` ونظام تنزيل السور.
- شاشة أذان كاملة تُفتح من إشعار الصلاة، مع خيار معاينتها من إعدادات الأذان. يلزم إضافة ملفات MP3 مرخصة إلى `assets/adhan/` حتى يتوفر الصوت؛ لا تتضمن هذه الحزمة تسجيلًا صوتيًا غير مرخص.
- رسالة الدعاء للمطور محمد حسني في صفحة «عن التطبيق».

## Cloud / الحسابات
الإصدار المعدل يضيف Supabase بشكل اختياري. بدون مفاتيح Supabase يعمل التطبيق محليًا كما كان. مع المفاتيح يصبح هناك تسجيل/دخول ومزامنة وواجهة مالك.
راجع `SUPABASE_SETUP.md` و `supabase/schema.sql`.

لبناء نسخة Cloud:
```bash
flutter pub get
flutter build apk --release --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```


## بناء نسخة Cloud المرتبطة
أضف GitHub Actions secrets باسم `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` كما هو موضح في `SUPABASE_SETUP.md`، ثم شغّل workflow من تبويب Actions. إذا لم تضف أيًا منهما، سيُبنى APK محلي دون حساب أو مزامنة؛ وإذا أضفت واحدًا فقط فسيفشل البناء برسالة توضيحية.

## تنزيل الأذان لأول مرة ثم تشغيله دون إنترنت

- افتح **إعدادات الأذان** واضغط تنزيل بجانب التسجيل المتاح.
- يُنزّل التطبيق التسجيل مرة واحدة إلى مساحة التطبيق الخاصة (`adhan_audio`) بصيغة OGG.
- بعد اكتمال التنزيل، يستخدم `just_audio` الملف المحلي؛ لا يحتاج تشغيله لاحقًا إلى اتصال بالإنترنت.
- إذا فشل التنزيل، تحقق من الاتصال وأعد المحاولة.
- التسجيل الافتراضي الحالي: `Beautiful_adhan.ogg` من Wikimedia Commons، أداء Adam-synagda، بترخيص CC0 1.0: https://commons.wikimedia.org/wiki/File:Beautiful_adhan.ogg

**ملاحظة Android:** صوت الإشعار نفسه يظل صوت تنبيه النظام؛ ملفات التنزيل الموجودة في مساحة التطبيق ليست Android `res/raw`. عند فتح شاشة الأذان من إشعار الوقت، يحاول التطبيق تشغيل الملف المحلي تلقائيًا. يلزم اختبار إذن الشاشة الكاملة وسلوك التشغيل عند قفل الهاتف على أجهزة فعلية قبل ضمان الأذان الكامل في كل الحالات.

## تحديث 4.1.0 — إصلاح التلاوة وتجديد الواجهة

- عند تبديل القارئ أثناء تلاوة القرآن، يحاول المشغل حفظ السورة وموضع التشغيل وحالة الإيقاف/التشغيل ثم فتح المصدر الجديد. إذا لم تكن هناك تلاوة نشطة، لا يبدأ صوت تلقائيًا.
- أصبح اختيار القارئ من صفحة القرآن والإعدادات يستخدم مسارًا موحدًا، مع معالجة فشل التبديل وإظهار رسالة للمستخدم.
- أضيف زر لتجربة كل قارئ بسورة الفاتحة قبل استخدامه، وأصبحت علامة التلاوة المحمّلة في قائمة السور مرتبطة بالقارئ المحدد، وتعرض صفحة التنزيلات اسم القارئ لكل ملف.
- جُدّد نظام الألوان ومكونات Material 3، ووُحّدت شارات الأيقونات، وأعيد ترتيب الاختصارات والرئيسية وصفحة «المزيد» مع بحث داخل أقسامها. جميع الميزات السابقة ما زالت متاحة.
- أُزيل تجاهل `pubspec.lock` من Git، وأصبحت خطوة تحليل Dart في GitHub Actions تفشل عند وجود أخطاء فعلية.
- يلزم تشغيل workflow بعد رفع التغييرات: لم تتوفر Flutter/Dart في بيئة إعداد هذه الحزمة، لذلك لم يُنشأ `pubspec.lock` ولم يُشغّل التحليل أو البناء هنا.
