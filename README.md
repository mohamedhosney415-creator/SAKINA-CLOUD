# سكينة — SAKINA 4.3.0

تطبيق إسلامي (Flutter / Android) بواجهة عربية RTL: مواقيت، أذان، قرآن، أذكار، ختمة، تقويم، رمضان، ويدجت.

> **حالة المشروع:** اختبارات Flutter الأربعة والتحليل نجحا دون أخطاء أو تحذيرات (تبقى رسائل معلومات عن واجهة Flutter القديمة في شاشة البداية). لم يُبنَ APK محليًا؛ ارفعه إلى GitHub وشغّل Actions، ثم اختبر النسخة الناتجة على الهاتف قبل النشر.
> راجع `STATUS.md` لمعرفة ما يحتاج تأكيدًا، و`TESTING_CHECKLIST.md` للاختبارات الإلزامية.

## البناء (APK) من GitHub
1. ارفع محتوى هذا المجلد كما هو إلى مستودع GitHub.
2. تبويب **Actions** ← **Build SAKINA APK** ← **Run workflow** (أو يعمل تلقائيًا مع كل push).
3. حمّل الملف من **Artifacts** ← `SAKINA-apk`.
4. إن فشل البناء: افتح سجل الخطوة الفاشلة وأرسل الخطأ كما هو لتصحيحه.

الـ workflow ينفّذ: `flutter create` ← `tool/patch_android.py` (الأذونات، الخدمات، الويدجت، صوت الأذان، Gradle) ← `flutter build apk --release`.

## ملفات الأذان
يأتي المشروع الآن مع `assets/adhan/sakina_adhan.ogg` كصوت افتراضي كامل لإشعار الأذان، بترخيص CC0. ينسخه `tool/patch_android.py` إلى موارد Android؛ لا تحذفه إذا أردت صوت الأذان الكامل عند إغلاق التطبيق. تسجيلات المؤذنين الإضافية في `assets/adhan/` تُستخدم داخل التطبيق. التفاصيل والمصدر والترخيص في `assets/adhan/README.txt`.

### الأذان عند قفل الهاتف أو إغلاق التطبيق

- يجدول التطبيق إشعارًا محليًا بدقة عالية لأربعة عشر يومًا، ويعيد الجدولة عند فتح التطبيق وبعد إعادة تشغيل الهاتف. يشغّل الإشعار ملف الأذان المرفق، ويستخدم تنبيه ملء الشاشة لعرض شاشة الأذان على شاشة القفل حيث يسمح Android بذلك.
- من **إعدادات الأذان** اسمح بالإشعارات والمنبهات الدقيقة، واضغط **إعداد إذن شاشة القفل**. في Android 14 وما بعده قد تحتاج إلى السماح بملء الشاشة من صفحة إعدادات التطبيق؛ يظهر الزر داخل إعدادات الأذان.
- النظام قد يمنع الصوت أو فتح الشاشة عند رفض الأذونات، أو تفعيل الصامت/عدم الإزعاج، أو إجبار التطبيق على الإيقاف من إعدادات الهاتف. بعض الشركات المصنّعة تقيّد الخلفية أيضًا؛ يلزم اختبار جهازك.
- تنبيه الإشعار يستخدم التسجيل الافتراضي المرفق، بينما صفحة الأذان تستخدم المؤذن الذي اخترته داخل التطبيق عند فتحها. اختبار الأذان الكامل على شاشة القفل بعد تثبيت APK ما زال مطلوبًا.

## ملاحظات تقنية
- المواقيت تُحسب محليًا بمكتبة `adhan` (الهيئة المصرية: الفجر 19.5° والعشاء 17.5°، مذهب شافعي للعصر) فتعمل بلا إنترنت وبتوقيت القاهرة مع التوقيت الصيفي.
- الأذان: إشعارات مجدولة (alarm exact) لـ14 يومًا وتُجدَّد كلما فُتح التطبيق، وتُعاد بعد إعادة تشغيل الهاتف عبر مستقبل الإقلاع.
- إشعار الصلاة يستخدم صوت أذان OGG مضمّنًا كـ Android raw resource مع قناة إشعار جديدة؛ التنبيهات الدقيقة وإذن ملء الشاشة يعتمدان على إعدادات الجهاز.
- نص القرآن يُحمَّل من api.alquran.cloud ويُحفظ محليًا. تلاوات معظم القراء تأتي من خوادم MP3Quran وفق [توثيق API الرسمي](https://www.mp3quran.net/eng/api)، واستخدمنا مسار شهريار پرهيزگار من [توثيق Quran Cloud CDN](https://alquran.cloud/cdn). ملفات التنزيلات تُحفظ منفصلة لكل قارئ.
- لا يطلب التطبيق GPS؛ اختيار المدينة يدوي. الحساب والمزامنة السحابية اختياريان. لا إعلانات أو أدوات تتبّع.

- توسيع قائمة القرّاء مع الاحتفاظ بمشغل `just_audio` ونظام تنزيل السور.
- شاشة أذان كاملة تُفتح من إشعار الصلاة، مع خيار معاينتها من إعدادات الأذان. يلزم إضافة ملفات MP3 مرخصة إلى `assets/adhan/` حتى يتوفر الصوت؛ لا تتضمن هذه الحزمة تسجيلًا صوتيًا غير مرخص.
- رسالة الدعاء للمطور محمد حسني في صفحة «عن التطبيق».

## Cloud / الحسابات
الإصدار المعدل يضيف Supabase بشكل اختياري. بدون مفاتيح Supabase يعمل التطبيق محليًا كما كان. مع المفاتيح يصبح هناك تسجيل/دخول ومزامنة وواجهة مالك.
راجع `SUPABASE_SETUP.md` و `supabase/schema.sql`.

لبناء نسخة Cloud:
```bash
flutter pub get
flutter build apk --release --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```


## بناء نسخة Cloud المرتبطة
أضف GitHub Actions secrets باسم `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` كما هو موضح في `SUPABASE_SETUP.md`، ثم شغّل workflow من تبويب Actions. إذا لم تضف أيًا منهما، سيُبنى APK محلي دون حساب أو مزامنة؛ وإذا أضفت واحدًا فقط فسيفشل البناء برسالة توضيحية.

## تنزيل الأذان لأول مرة ثم تشغيله دون إنترنت

- افتح **إعدادات الأذان** واضغط تنزيل بجانب التسجيل المتاح.
- يُنزّل التطبيق التسجيل مرة واحدة إلى مساحة التطبيق الخاصة (`adhan_audio`) بصيغة OGG.
- بعد اكتمال التنزيل، يستخدم `just_audio` الملف المحلي؛ لا يحتاج تشغيله لاحقًا إلى اتصال بالإنترنت.
- إذا فشل التنزيل، تحقق من الاتصال وأعد المحاولة.
- التسجيل الافتراضي الحالي: `Beautiful_adhan.ogg` من Wikimedia Commons، أداء Adam-synagda، بترخيص CC0 1.0: https://commons.wikimedia.org/wiki/File:Beautiful_adhan.ogg

**ملاحظة Android مهمة:** إشعار الصلاة يستخدم الآن ملف `sakina_adhan.ogg` المضمّن في `res/raw` كصوت قناة Android؛ لا يعتمد الصوت الافتراضي على تنزيل من الإنترنت. عند فتح شاشة الأذان، قد يبدأ أيضًا تشغيل تسجيل المؤذن الذي اختاره المستخدم من مساحة التطبيق الخاصة. سلوك الصوت طويل المدة وفتح النشاط يتأثران بإصدار Android وإعدادات القناة والجهاز؛ اختبرهما لتجنب انقطاع الصوت أو تداخله.

لأفضل فرصة للتنبيه: فعّل إشعارات سكينة، واسمح بالإشعارات والمنبّهات الدقيقة وإذن «ملء الشاشة» إن عرضه Android (من إعدادات الأذان/أذونات التطبيق). إذا رُفض إذن المنبّه الدقيق، يستخدم التطبيق جدولة غير دقيقة وقد يتأخر التنبيه. Android قد يمنع نافذة ملء الشاشة عندما يكون التطبيق ظاهرًا، وقد يكتفي بإشعار منبثق. أذونات الإشعارات/المنبّهات، وضع عدم الإزعاج أو الصامت، إعدادات قناة الأذان، قيود البطارية الخاصة بالشركة المصنّعة، والإيقاف الإجباري للتطبيق قد تمنع أو تؤخر التنبيه/الصوت. بعد الإيقاف الإجباري لا تُضمن التنبيهات حتى فتح التطبيق مجددًا. يلزم اختبار على الجهاز المستهدف.
