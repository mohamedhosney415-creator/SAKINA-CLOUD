# SAKINA Adhan audio sources

Adhan recordings are downloaded only after the user chooses a voice. Files are stored in the app's private support directory and reused offline.

## Catalog sources

- AlAdhan Download Adhans: https://aladhan.com/download-adhans
  - Ahmad al-Nafees (`a1.mp3`)
  - Hafiz Mustafa Özcan (`a2.mp3`)
  - Mishary Rashid Alafasy (`a4.mp3`, `a7.mp3`, `a9.mp3`)
  - Mansour Al-Zahrani (`a11-mansour-al-zahrani.mp3`)
- Kiwifu Adhan MP3 collection: https://github.com/Kiwifu/adhan-mp3
  - Abdul Basit Abdus Samad regular and Fajr recordings.
- Wikimedia Commons `Beautiful_adhan.ogg`, CC0 1.0: https://commons.wikimedia.org/wiki/File:Beautiful_adhan.ogg

The catalog links point to their respective source hosts. Before publishing a commercial or widely distributed build, retain the source attribution and review the terms/rights applicable to each individual recording. A publicly downloadable file is not, by itself, proof that every recording is public domain.
